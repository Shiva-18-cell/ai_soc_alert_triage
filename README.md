# AI-Powered SOC Alert Triage & False Positive Reduction Platform

## Problem

SOC analysts receive large volumes of security events from SIEM
platforms such as Splunk and Wazuh.

Manually reviewing, correlating and prioritizing these events is
time-consuming and can lead to alert fatigue.

## Objective

Build a system that:

- parses security events
- normalizes event data
- correlates related events
- identifies suspicious patterns
- identifies likely false positives
- prioritizes alerts
- provides investigation context
- assists analysts using AI
